# ResultRank

ResultRank is the ultimate leaderboard portal for education board results in Bangladesh. It provides a unified platform to explore top-performing students, schools, and analyze detailed GPA statistics across all education boards.

## Features
- **All Boards Supported:** View leaderboards for Dhaka, Dinajpur, Rajshahi, Cumilla, Chattogram, Sylhet, Barishal, Jashore, Mymensingh, Madrasah, and Technical boards.
- **Exam Filters:** Easily toggle between SSC and HSC results.
- **Yearly Archives:** Access historical result leaderboards for multiple years.
- **Clean Interface:** A fast, responsive, and intuitive design built for quick access to vital academic statistics.

A product by [HSCStack](https://hscstack.site) — Empowering the next generation of students with high quality, direct, and accessible academic resources.
